# Pokéidle HUB

Aplicativo para Windows que roda as suas contas do [Pokéidle.io](https://pokeidle.io), sem inteligência artificial, com as
regras que você configura. Feito por [Pumba Developer](https://www.pumbadev.com).

Este repositório guarda só os instaladores. Baixe a versão mais nova em **Releases**:
[PokeidleHub-Setup.exe](https://github.com/pumba-dev/pokeidle-hub/releases/latest/download/PokeidleHub-Setup.exe).

## Instalar

- Windows 10 ou 11, 64 bits. O instalador não pede administrador e instala só para o seu usuário.
- O instalador não tem assinatura de código: o Windows mostra "O Windows protegeu o computador" e "Editor desconhecido".
  Clique em **Mais informações** e depois em **Executar assim mesmo**. Com o Smart App Control ligado, o Windows não deixa
  instalar.
- O app precisa do WebView2 Runtime da Microsoft, que já vem no Windows 11 e em quase todo Windows 10. Se faltar, o app
  mostra o link oficial.
- Depois de instalado, o app se atualiza sozinho: baixa a versão nova e a instala quando você fecha o HUB.

## O que o HUB nunca faz

O HUB nunca lê nem guarda a sua senha (você entra na própria tela do jogo), nunca deposita nem saca Gemas, nunca envia
Coins e nunca passa valor entre as suas contas.
